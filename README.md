# 🏅 desempenho-atletas-doencas

Análise de dados sobre o **desempenho de atletas com doenças**, desenvolvida com Python. Estudo sobre como atletas de alto rendimento lidam com condições médicas e mantêm sua performance.

---

## 📋 Sobre o Projeto

Este repositório faz parte de um projeto de **Ciência de Dados** que analisa o desempenho de atletas que possuem ou tiveram doenças diagnosticadas. O foco está em entender padrões e tendências na performance esportiva mesmo diante de desafios de saúde.

---

   ```bash
   pip install pandas matplotlib
   ```
